# EID ROOT

<div dir="rtl">

تطبيق أندرويد لتنزيل وتثبيت إضافات Zygisk وتطبيقات إدارة الروت بسهولة، عن طريق Magisk أو KernelSU.

## الإضافات

| الإضافة | المصدر |
|---|---|
| NeoZygisk | [JingMatrix/NeoZygisk](https://github.com/JingMatrix/NeoZygisk) |
| Vector | [JingMatrix/Vector](https://github.com/JingMatrix/Vector) |
| NoHello | [MhmRdd/NoHello](https://github.com/MhmRdd/NoHello) |
| HMA-OSS Zygisk | [frknkrc44/HMA-OSS](https://github.com/frknkrc44/HMA-OSS) |
| AlwaysStrong (Inject) | [Evokerr/AlwaysStrong](https://gitlab.com/Evokerr/AlwaysStrong) على GitLab |

## التطبيقات

KernelSU Manager، Vector Manager، GpsSetter، Magisk، HMA-OSS Manager.

## كيف يشتغل

- ينزّل كل إضافة من آخر إصدار رسمي في مستودعها، وإذا فشل يستخدم رابطًا ثابتًا.
- يثبّت الإضافات بصلاحية الروت ثم يعيد تشغيل الجهاز.
- الإضافات لا تأتي داخل التطبيق، بل تُنزَّل من مصادرها وقت التثبيت.

## المتطلبات

- أندرويد 10 أو أحدث.
- جهاز عليه روت (Magisk أو KernelSU).
- اتصال بالإنترنت.

## التثبيت

نزّل ملف APK من صفحة [Releases](../../releases).

إذا كانت عندك نسخة سابقة من EID ROOT موقّعة بمفتاح مختلف، احذفها قبل التثبيت.

## تنبيه

- التطبيق يثبّت إضافات بصلاحية الروت تعدّل في النظام. استخدمه على مسؤوليتك، وخذ نسخة احتياطية قبل الاستخدام.
- الإضافات من مطوريها، وكل إضافة تخضع لترخيص مستودعها.
- قد تتعارض إضافات Zygisk مع بعضها (مثل ReZygisk مع NeoZygisk)، فاحذف المتعارضة قبل التثبيت.
